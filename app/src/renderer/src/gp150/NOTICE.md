# Notices

This GP-150 toolkit is written from scratch from protocol facts. The third-party material is the effect catalog and the test vectors below.

- **majabojarska/Valeton-GP180-Rev-Eng**: GPL-3.0. The GP-180 speaks the GP-150's protocol and uses the same `.prst` file.
  - Protocol facts come from its USB captures (`corpus`): framing, check bytes, ACKs, resend requests, commands, settings records. The codec re-encodes every one of its 8 980 frames byte for byte.
  - The test vectors (`tests/vectors.mjs`) are frames from those captures and one preset from its `prst-dump/`.
  - The built-in effect catalog (`lib/catalog-data.mjs`) is generated by `app/scripts/gp150-catalog-from-gp180-re.mjs` from its `effect-wire-schema.json` at commit 11edfe5. That file normalizes Valeton Suite 2.1.0's `module150_data.json`.
- **Facts only, no code or text copied**: AlbertoBarba's GP150_PRST_FORMAT.md (gist, no licence). Source of the preset layout notes and of the report that the pedal accepts a file whose checksum field is 0.
- **Not included**: Valeton Suite, its module data file, effect descriptions, the factory presets as a bank, and firmware. The simulator generates its bank. Its settings start from one 0x2000 reply in the captures.
